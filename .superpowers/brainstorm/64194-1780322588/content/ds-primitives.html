Implementation note
All 13 components go into a single ds.jsx file. No CSS modules — they use inline styles and existing shell.css class names (layer-1, layer-2, du3-cta, etc.). DataTable is the most complex — it wraps a styled table with sortable headers, used by Portfolio and Transactions.
